# Double Pendulum — Win32 / C++

Двойной маятник на чистом Win32 API, без сторонних библиотек и движков. Учебный проект: цель была разобраться с классами, игровым циклом и физикой в C++, а не сделать красивую игру.

## Что делает

Окно на весь экран, белый фон. Два груза на нитях: первый закреплён к точке сверху, второй — к первому. Оба качаются под действием гравитации. Движение хаотическое — это свойство двойного маятника, а не баг.

## Реализовано

- Окно без рамки на весь экран (WS_POPUP + GetSystemMetrics)
- Двойная буферизация: рисование в память, потом BitBlt на экран
- Класс Pendulum: углы, угловые скорости, точка подвеса, длины нитей
- Угловые ускорения по формулам двойного маятника
- Обновление скоростей и углов с фиксированным шагом (dt)
- Рисование нитей и грузов разного цвета через GDI
- Выход по Esc

## Как запустить

Открыть .sln в Visual Studio, собрать (Debug или Release), запустить. Требуется Windows.

## Заметки по реализации

- Шаг физики dt = 0.1f подобран экспериментально. При меньшем значении движение плавнее, но медленнее; при большем — маятник может «взорваться» из-за накопления ошибки.
- Начальные углы специально разные (1.5 и 1.0 рад), иначе в первые кадры вторая нить почти не реагирует.
- Формулы угловых ускорений взяты из стандартного вывода для двойного маятника с одинаковыми массами. Вывод не делал — для проекта это не требуется.
